# BigDiscoJS brand kit

The BigDiscoJS visual system pairs a citrus-bright accent with deep technical
surfaces and restrained warm highlights.

| Token | Hex | Use |
| --- | --- | --- |
| Lemon | `#D8FF3E` | Primary accent and key highlights |
| Lime | `#9BEA16` | Secondary accent and glow |
| Forest | `#12351D` | Deep green surfaces |
| Ink | `#050906` | Background and high-contrast base |
| Pollen | `#FFF36A` | Small warm highlight details |
| Cloud | `#F5F8EC` | Primary text on dark surfaces |

## Assets

- `bigdiscojs-logo.png` — compact repository mark
- `bigdiscojs-banner.png` — wide README/banner artwork with left-side space
- `bigdiscojs-social-preview.png` — GitHub social preview with title and tagline

The assets were generated as a coordinated set for BigDiscoJS and are separate
from the legacy BigDPP branding.
